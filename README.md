# mini-web-projects

바닐라 HTML/CSS/JavaScript로 만든 작은 웹 프로젝트 모음입니다.

## 프로젝트 목록

### 🍅 pomodoro-tracker
뽀모도로 타이머와 할 일 목록, 집중 통계를 함께 제공하는 생산성 트래커입니다.

### 🔗 word-chain
15초 안에 끝말잇기 단어를 입력하는 간단한 미니 게임입니다.

### ✨ particle-playground
클릭·드래그로 파티클을 뿌리며 중력, 바람, 색상 모드를 조절해보는 캔버스 놀이터입니다.

## 실행 방법

각 프로젝트 폴더의 `index.html`을 브라우저로 직접 열어도 되고, 저장소 루트의 정적 서버 스크립트를 사용할 수도 있습니다.

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

기본적으로 `http://localhost:8080`에서 서비스됩니다. 예를 들어 뽀모도로 트래커는 `http://localhost:8080/pomodoro-tracker/index.html`에서 열 수 있습니다.
